# Product Overview

Formah App is a fitness workout tracking application built with expo. The app helps users create, manage, and execute workout templates with exercise tracking capabilities.

## Core Features

- **Start Workout**: Browse and select workout templates, view workout history and consistency metrics
- **Template Management**: Create custom workout templates with multiple exercises
- **Exercise Selection**: Browse, search, and filter exercises by body part and equipment category
- **Template Archiving**: Archive and restore workout templates

## User Flow

1. Users start from the workout home screen showing available templates
2. Create new templates by selecting exercises from a comprehensive library
3. View workout history and consistency metrics
